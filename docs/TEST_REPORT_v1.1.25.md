## 三、全量 Bug 修复记录 (v1.1.19 ~ v1.1.25)

### v1.1.20
- **TC-TK-11 令牌搜索无结果**: 搜索改为模糊匹配（前缀匹配 → LIKE 通配），并支持管理员搜全量（去掉 user_id 过滤）。commit `5a08aa2`
- **TC-TK-12 令牌复制按钮**: 有意移除令牌列表「复制聊天按钮」，防 Key 泄露。commit `f509af4`

### v1.1.21
- **TC-AUTH-08 生成系统访问令牌「id 为空！」**: `GenerateAccessToken` 移除 `if role >= 10 { id = 0 }` 覆盖（list 接口的「admin 看全量」逻辑被误抄），改用当前用户 id。commit `8e693f0`
- **TC-TK-07 月度额度整数截断（前端）**: 编辑令牌表单 quota 用 `parseInt` 导致非整数值被截断为 0，改为 `parseFloat` + `Math.round`。commit `8e693f0`

### v1.1.22
- **TC-AUTH-05/06 用户自助修改密码**: One API 原生无自助改密码入口，仅管理员在用户编辑页改。新增 `POST /api/user/password`（`ChangePassword`，旧密码 `ValidatePasswordAndHash` 校验 + 新密码 ≥8 位 + 两次一致），前端 `PersonalSetting.js` 三字段表单。commit `5287897`

### v1.1.23
- **TC-TK-07 月度额度静默丢失（后端）**: `UpdateToken` 未赋值 `cleanToken.MonthlyQuota`，且 `model/token.go` `Update()` 的 `Select()` 白名单缺 `monthly_quota`，导致编辑令牌时月度额度被静默清 0。修复：`controller/token.go` 赋值 + `Select()` 补字段。commit `be0da06`

### v1.1.24
- **TC-FOOT-05 关于页未显示版本号**: `About/index.js` 新增 `loadVersion` 读取 `/api/status`，显示「当前版本：{version}」。commit `9a55efd`

### v1.1.25
- **TC-SET-03 QuotaPerUnit 保存失败**: `OperationSetting.js` 提交 option 时 `value` 为数字类型，后端解析失败；改为 `value: String(value)`。commit `9a55efd`

## 五、新发现 UI 缺陷 (c2-tk08)

- **关联用例**: TC-TK-08「编辑令牌——仅改范围不改 models」（后端逻辑 ✅ 通过）
- **缺陷现象**: 编辑令牌表单「模型范围」下拉框回显为空——进入编辑页时下拉框不显示该令牌已有模型，但 API `GET /api/token/:id` 返回的 `models` 字段正常。
- **影响范围**: 仅前端 `EditToken.js` 回显逻辑；不影响后端数据正确性（保存后 `models` 不被清空，TC-TK-08 已通过）。
- **严重程度**: 低（UI 显示问题，无数据风险）。
- **状态**: 待修复，记录在案，不阻塞本轮验收。
