## 四、已知缺陷 (3 项)

### ❌ 缺陷 1: TC-CH-11 — 渠道列表 key 全隐藏（非掩码）
- **现象**: 渠道列表密钥列整串隐藏，未按预期显示 `sk-****...` 掩码格式
- **预期**: 密钥应脱敏显示为 `sk-****` 掩码，便于管理员辨识是哪个 key
- **影响**: 管理员无法从列表辨识渠道对应的 key
- **优先级**: 中

### ❌ 缺陷 2: TC-FOOT-05 — 关于页无版本号
- **现象**: 关于页未显示版本号
- **预期**: 显示 `Asterisk Token Router` + 版本号（如 `1.1.20`）
- **影响**: 用户无法从页面确认当前部署版本
- **优先级**: 低

### ⚠️ 缺陷 3: 额度显示单位表述差异
- **现象**: 额度相关字段在不同页面单位表述不一致（¥ 金额 / 元 / 额度数字 / 余额/用量 混用）
- **预期**: 统一额度显示单位与表述口径（内部单位 1,000,000:1 换算为 ¥ 展示）
- **影响**: 表述不统一，易引起用户误解
- **优先级**: 低
