## 四、已知缺陷

### ❌ TC-TK-11: 令牌搜索 BUG
- **现象**: 在管理员令牌列表搜索框中输入"测试"，无任何结果返回
- **预期**: 应显示名称包含"测试"的令牌
- **影响**: 管理员无法通过搜索快速定位令牌
- **优先级**: 中

### ⚠️ TC-TK-12: 无复制按钮
- **现象**: 管理员令牌列表每行操作列缺少「复制」按钮
- **预期**: 应有复制按钮，点击后复制 `sk-` + 完整密钥
- **影响**: 管理员无法从列表直接复制令牌 Key
- **优先级**: 中

- **剩余 42 用例**: 涵盖 API 权限边界测试、用户管理完整流程、Dashboard/日志/设置功能验证，建议下轮统一测试
