# #ESG: ESG 智能评级与服务平台 - 开发规划

> 项目标识: #ESG
> 网站: https://esgbot.cn
> 主体: 上海锐钝信息科技（沪ICP备2025119352号-1）
> 创建日期: 2026-08-04

---

## 一、项目定位

**一句话**: 面向中国资本市场的 ESG 评级智能检索 + 舆情监控 + 线索举报 + 专家服务平台。

**目标用户**:
1. 投资者/分析师 — 检索企业 ESG 评级，监控 ESG 风险事件
2. 上市公司 — 查看自身 ESG 表现，主动管理声誉
3. 公众/NGO — 上报 ESG 负面事件线索
4. ESG 咨询师 — 入驻平台提供评级/咨询服务

**差异化**: 
- 聚合多源 ESG 评级（华证/商道融绿/万得/中证等），而非自建评分体系
- AI 驱动的全网舆情事件 ESG 影响分析
- C 端/B 端双入口

## 二、市场概览

### 2.1 市场规模

| 指标 | 数据 |
|------|------|
| A股 ESG 报告披露 | 2500+ 家公司（2024），同比 +5% |
| ESG 公募基金规模 | 2682 亿元（2025 Q2） |
| ESG 贴标债券 | 1.01 万亿元（2025 前 9 个月） |
| PRI 签署机构（中国） | 128 家 |
| ESG 评级覆盖 | 中证覆盖 ~5000 家 A 股 |

### 2.2 核心竞品

| 机构 | 特点 | 不足 |
|------|------|------|
| 华证 | 全覆盖 A 股 + 基金 ESG 评级，方法论透明 | B 端为主，无 C 端入口 |
| 商道融绿 | 中国最早，2015 年起覆盖 A+H 股 | 数据需付费 |
| 万得 ESG | 12000+ 主体，全透明底层数据 | 重度绑定 Wind 终端 |
| 妙盈科技 | 学术评估最佳（4A1B） | 透明度不足 |
| 中诚信绿金 | 科学性+相关性优秀 | 预测性待提升 |

### 2.3 市场缺口

> **无人做 ESG 评级的「大众点评」** — 聚合评级 + 舆情 + 用户上报的公共平台。

## 四、功能模块规划

### Phase 1: MVP
1. 企业 ESG 评级检索（搜索+筛选+对比）
2. 企业详情页（评级历史+ESG 三个维度雷达图+事件时间线）
3. 用户注册/登录
4. 舆情事件自动采集+ESG 影响标记

### Phase 2: 扩展
5. 用户上报 ESG 负面线索
6. 线索审核+公示+企业回应
7. 专家/咨询师入驻+资质审核
8. 咨询服务撮合+在线支付

### Phase 3: 商业
9. 企业 ESG 主页（付费认证）
10. API 数据服务订阅
11. 定制报告生成（AI）
