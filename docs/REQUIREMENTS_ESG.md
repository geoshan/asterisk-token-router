## 1. 项目概述

本项目旨在构建一个ESG评级数据聚合与分析平台，整合国内主流ESG评级机构（华证、商道融绿、万得ESG、中证、妙盈科技）的评级数据，并结合舆情数据，为投资决策提供全面的ESG风险评估。

### 1.1 核心目标

- 聚合五家国内主流ESG评级机构的评级数据
- 整合ESG舆情事件数据
- 提供评级对比、趋势分析、舆情影响量化等功能
- 支撑ESG投资策略研究

### 1.2 覆盖评级机构

| 序号 | 机构名称 | 发布年份 | 类型 | 覆盖范围 |
|------|----------|----------|------|----------|
| 1 | 华证指数 | 2018 | 指数公司 | A股 + 港股（市值覆盖率95%） |
| 2 | 商道融绿 | 2015 | ESG服务商 | A股 + 港股通 + 债券发行人 |
| 3 | 万得 (Wind) | 2021 | ESG服务商 | 大中华区超过12,000家公司主体 |
| 4 | 中证指数 | 2020 | 指数公司 | A股 + 港股 + 发债主体 |
| 5 | 妙盈科技 (MioTech) | 2017 | ESG服务商 | A股 + 港股 + 台股 + 美股中概股（80万+企业） |

## 2. 功能需求 - Phase 1

### 2.1 数据接入层

- **评级数据接入**: 按各评级机构更新频率同步ESG评级数据（综合得分、E/S/G分项得分、评级等级）
- **底层指标数据接入**: 同步各机构的底层指标得分（按可得性）
- **舆情数据接入**: 接入ESG争议事件数据（含事件类型、严重程度、发生时间、衰减周期）

### 2.2 数据标准化

- 跨机构评级映射表（AAA-C、A+-D、7/9/10/12档互转）
- 行业分类对齐（申万/GICS/MICS → 统一行业分类）
- 时间序列对齐（月度快照 + 事件触发更新）

### 2.3 基础查询与对比

- 单公司多机构评级对比
- 行业ESG评级分布
- 评级变化追踪（升级/降级历史）

### A.1 华证ESG评级方法论

#### A.1.1 基本概况

| 属性 | 说明 |
|------|------|
| **发布机构** | 上海华证指数信息服务有限公司 |
| **首次发布** | 2018年 |
| **当前版本** | V2.1（2024年5月更新） |
| **指标层级** | 5级：3支柱 → 16主题 → 44议题 → 近80底层指标 → 300+数据指标 |
| **覆盖范围** | 全部A股上市公司 + 具有可投资性的港股上市公司（港股市值覆盖率达95%） |
| **更新频率** | 每季度更新 |
| **评级等级** | 9档：AAA / AA / A / BBB / BB / B / CCC / CC / C |
| **数据来源** | 市场公开信息、发行人正式文件、AI大数据引擎（NLP + 语义分析） |

#### A.1.2 指标体系框架

| 3大支柱 | 16个主题 | 44个关键议题 |
|---------|----------|-------------|
| **环境 (E)** | 气候变化 | 温室气体排放、碳减排路线、应对气候变化、海绵城市、绿色金融 |
| | 资源利用 | 土地利用及生物多样性、水资源消耗、材料消耗 |
| | 环境污染 | 工业排放、有害垃圾、电子垃圾 |
| | 环境友好 | 可再生能源、绿色建筑、绿色工厂 |
| | 环境管理 | 可持续认证、供应链管理-E、环保处罚 |
| **社会 (S)** | 人力资本 | 员工健康与安全、员工激励和发展、员工关系 |
| | 产品责任 | 品质认证、召回、投诉 |
| | 供应链 | 供应商风险和管理、供应链关系 |
| | 社会贡献 | 普惠、社区投资、就业、科技创新 |
| | 数据安全与隐私 | 数据安全与隐私 |
| **公司治理 (G)** | 股东权益 | 股东权益保护 |
| | 治理结构 | ESG治理、风险控制、董事会结构、管理层稳定性 |
| | 信披质量 | ESG外部鉴证、信息披露可信度 |
| | 治理风险 | 大股东行为、偿债能力、法律诉讼、税收透明度 |
| | 外部处分 | 外部处分 |
| | 商业道德 | 商业道德、反贪污和贿赂 |

#### A.1.3 权重设定方法

华证指数按行业属性对三级议题指标设置权重，核心原则：

- **影响程度 × 影响时间矩阵**：影响程度高的权重更高，影响时间短的权重更高
- 对于非行业核心议题指标，权重直接设为0
- 各行业差异化权重设定

| 影响时间 | 短期 | 中期 | 长期 |
|----------|------|------|------|
| **高影响程度** | 最高权重 | 递减 | 较低 |
| **中影响程度** | 递减 | 中等 | 较低 |
| **低影响程度** | 最低权重 | — | — |
| **无影响** | 权重为0 | — | — |

#### A.1.4 行业调整机制（V2.1新增）

自下而上加权计算ESG分数后，分行业标准化调整：

```
最终ESG分数 = 50 × (原始加权分数 - 行业最低分) / (行业最高分 - 行业最低分) + 50
```

- 行业最高分取行业内ESG评级前5%区间
- 行业最低分取行业内ESG评级后5%区间
- 排除近2年新上市公司以避免拉低行业基准
- 行业最低分>70时设为70，最高分<90时设为90

#### A.1.5 ESG尾部风险模型

华证指数另设ESG尾部风险评价模型，从五个维度监控：

1. **违法违规** — 证监会处罚、行政处分
2. **负面经营事件** — 生产事故、产品召回
3. **大股东行为** — 股权质押、资金占用
4. **过度扩张** — 商誉减值风险
5. **财务可信度** — 财务造假、审计意见

尾部风险分四类：严重警告、警告、关注、低风险

#### A.1.6 评级分数与等级对应

| ESG评级 | 行业调整后ESG分数区间 |
|---------|---------------------|
| AAA | 分数 ≥ 95 |
| AA | 90 ≤ 分数 < 95 |
| A | 85 ≤ 分数 < 90 |
| BBB | 80 ≤ 分数 < 85 |
| BB | 75 ≤ 分数 < 80 |
| B | 70 ≤ 分数 < 75 |
| CCC | 65 ≤ 分数 < 70 |
| CC | 60 ≤ 分数 < 65 |
| C | 分数 < 60 |

### A.2 商道融绿ESG评级方法论

#### A.2.1 基本概况

| 属性 | 说明 |
|------|------|
| **发布机构** | 商道融绿 (SynTao Green Finance) |
| **首次发布** | 2015年（国内最早发布上市公司ESG评级的机构） |
| **指标层级** | 4级：3维度 → 14议题 → 200+指标 → 700+数据点 |
| **覆盖范围** | 全部A股（约4,845家）+ 港股通中的香港上市公司 + 主要债券发行人 |
| **更新频率** | 每季度更新 |
| **评级等级** | 10档：A+ / A / A- / B+ / B / B- / C+ / C / C- / D |
| **数据来源** | 公开信息披露、企业年报、ESG/CSR报告、政府数据、媒体报道 |
| **国际认可** | 中国唯一登陆彭博(Bloomberg)金融终端的ESG供应商；中国外汇交易中心(CFETS)使用其数据构建ESG高等级债券指数 |

#### A.2.2 指标体系框架

商道融绿ESG评级体系由三级构成：

- **一级指标**: 环境(E)、社会(S)、公司治理(G)三个维度
- **二级指标**: 14个核心议题（含13项分类议题 + 负面事件监控）
- **三级指标**: 200+具体ESG指标，基于1000+数据点评分

**14个ESG核心议题**涵盖：

| 维度 | 核心议题 |
|------|----------|
| **环境(E)** | 环境目标、环境管理、环境披露、环境负面事件 |
| **社会(S)** | 劳工政策、员工政策、女性员工、多样化、供应链责任管理、产品责任、社区影响、社会负面事件 |
| **治理(G)** | 治理结构、商业道德、治理负面事件 |

#### A.2.3 权重设定方法

- **51个行业模型**：根据行业特性设置差异化权重
- 通用指标 + 行业特定指标（行业特定指标仅适用于特定行业分类下的公司）
- 权重考量因素：行业特征 + 重点利益相关方关注问题
- 重点关注企业在各项议题的**管理水平**和**风险暴露**程度

#### A.2.4 评分流程

每个评级周期内：
1. 收集近1000个数据点
2. 对200+个ESG指标进行打分
3. 通过51个行业模型加权汇总
4. 得到ESG得分（0-100）及ESG评级（A+至D，共10等级）

#### A.2.5 评级特点

- 评估侧重"管理规划 → 管理执行 → 管理绩效"的管理过程
- 负面信息作为调整因子
- 评估结果整合了通用指标和行业特定指标
- 2020年起独家整合到彭博终端

### A.3 万得ESG (Wind ESG) 评级方法论

#### A.3.1 基本概况

| 属性 | 说明 |
|------|------|
| **发布机构** | 万得信息技术股份有限公司 (Wind) |
| **首次发布** | 2021年 |
| **指标层级** | 3级：3维度 → 25-29个议题 → 300-500+具体指标 |
| **覆盖范围** | 大中华地区超过12,000家公司主体（A股 + 港股 + 债券发行人） |
| **更新频率** | 综合得分每日更新；评级不定期更新（得分变动超阈值时自动触发） |
| **评级等级** | 7档：AAA / AA / A / BBB / BB / B / CCC |
| **数据来源** | 20,000+数据源：上市公司年报/ESG报告/社会责任报告、13,000+政府及监管部门、8,000+新闻媒体/网络舆情、800+行业协会/NGO |

#### A.3.2 评分体系架构

Wind ESG评级体系由两大部分组成：

**Part 1: 管理实践得分（满分7分）**
- 细分为25-29个议题（2024年更新至29议题）
- 下设300-500+具体指标
- 评估长期ESG基本面的影响

**Part 2: 争议事件得分（满分3分）**
- 基于新闻舆情、监管处罚、法律诉讼等多维度评估
- 反映短期突发事件的影响
- 每日更新，AI驱动实时监控

**综合得分 = 管理实践得分 + 争议事件得分**

#### A.3.3 管理实践指标体系

| 维度 | 核心议题（部分） |
|------|------------------|
| **环境(E)** | 环境管理、能源与气候变化、生物多样性、废水、水资源、原材料与废弃物、废气、绿色金融、绿色建造 |
| **社会(S)** | 雇佣、发展与培训、研发与创新、客户、职业健康与安全生产、信息安全与隐私保护、社区、医疗可及性、可持续产品、供应链 |
| **治理(G)** | 公司治理、商业道德、ESG治理、董监高、贪污腐败、股权及股东、审计、反垄断与公平竞争 |

#### A.3.4 动态更新机制

- **综合得分每日更新**：AI引擎实时处理ESG底层数据变更
- **评级触发更新**：当综合得分相对上一评级日变动超过1.5分时，评级自动更新
- **争议事件实时监控**：重大争议事件发生后立即结构化并影响得分
- **年度方法论评审**：每年进行整体性回顾和调整，与学术机构、高校、投资者、上市公司等沟通反馈

#### A.3.5 评级特点

- 全透明底层数据及评分结果
- 行业权重差异化设定
- 数据源覆盖广度国内领先（20,000+数据源）
- 提供基金ESG评级、碳排放数据库等延伸产品

#### A.4.3 评价特点

1. **兼顾国际惯例与本土实际**：基于联合国SDGs、UN PRI等国际标准，立足国内经济与市场发展实际
2. **兼顾风险管理与机遇**：同时考察ESG风险和企业改善风险的投入与效果，关注可持续发展背景下的成长机会
3. **一票否决机制**：对存在严重负面事件（重大环境污染、重大危害公共安全、重大财务造假）的公司实行一票否决
4. **临时调整机制**：除月度更新外，发生重大ESG争议事件时进行及时更新

#### A.4.4 权重设定

- 权重参考核心因素：**企业所处行业特征、数据可得性、有效性以及质量**
- 分行业差异化权重设置
- ESG指数开发方面国内领先（截至2025年12月累计发布ESG类指数122条）

### A.5 妙盈科技 (MioTech) ESG评级方法论

#### A.5.1 基本概况

| 属性 | 说明 |
|------|------|
| **发布机构** | 妙盈科技 (MioTech)，香港金融科技公司 |
| **首次发布** | 2017年 |
| **指标层级** | 4级：3维度 → 19议题 → 700+指标 → 1000+数据点 |
| **覆盖范围** | A股（约4,677家）+ 港股 + 台股 + 美股中概股（总计覆盖80万+企业） |
| **更新频率** | 每季度更新 |
| **评级等级** | 12档：A+ / A / A- / B+ / B / B- / C+ / C / C- / D+ / D / D- |
| **数据来源** | 传统自我披露（年报/ESG报告）+ 另类数据（新闻/社交媒体） + NLP知识图谱 |

#### A.5.2 指标体系框架

| 维度 | 核心议题 |
|------|----------|
| **环境(E)** | 环境管理、污染物、废弃物、物料消耗、水资源、能源消耗、温室气体排放、气候变化、生物多样性 |
| **社会(S)** | 劳工管理、员工参与度与多样性、职业健康与安全、社区影响、产品责任、供应商管理 |
| **治理(G)** | 商业道德、公司治理、风险管理、ESG治理 |

#### A.5.3 权重设定方法

- **自研MICS行业分类系统**：分为62个二级行业
- 综合考虑：行业特征 + 地域特征 + 市场特征 + 公司特定因素
- 针对每个公司，同时考虑其具体业务、所处行业和地理位置，确定各议题的风险权重
- 引入"中国式现代化建设"议题：乡村振兴、共同富裕等中国特色指标

#### A.5.4 评级特点

- **高量化程度**：底层指标超过700个，以定量数据为主，主观判断最小化
- **AI驱动**：利用机器学习和知识图谱技术处理280+ESG数据点
- **另类数据**：结合传统披露与社交媒体新闻等非主流ESG数据源
- **覆盖广度**：覆盖80万+中国民营企业和上市公司
- **学术评价**：在上海财经大学"中国主流ESG评级的再评估"研究中综合排名第一（4A1B），科学性、可靠性、相关性和预测性均评为A等级

## 附录B: 舆情影响机制

### B.1 ESG舆情事件的定义与分类

#### B.1.1 定义

ESG舆情事件（ESG Controversies/ESG Incidents）是指企业在环境、社会或公司治理方面发生的、被公开报道且可能对企业声誉和经营产生负面影响的争议性事件。

Clarity AI将其定义为："企业与任何社会主体或利益相关方之间发生的、以违反全球负责任商业行为规范（如UNGC原则、ILO原则、OECD跨国公司准则）为背景的冲突实例。"

#### B.1.2 事件分类体系

##### 按维度分类（三大类 + 子类）

### B.2 舆情事件对ESG评级的影响机制

#### B.2.1 影响路径

ESG舆情事件通过以下路径影响评级：

```
舆情事件 → 媒体报道 → 利益相关方反应 → 评级机构监控 → 评分调整
                ↓
         投资者卖出 → 股价下跌 → 市值损失
                ↓
         监管介入 → 处罚/诉讼 → 额外成本
                ↓
         消费者抵制 → 收入下降 → 品牌折损
```

#### B.2.2 各评级机构对争议事件的处理机制

| 评级机构 | 争议事件处理方式 |
|----------|------------------|
| **华证** | 设立独立的ESG尾部风险模型（5维度），分"严重警告/警告/关注/低风险"四类。争议事件与ESG评级并行，独立警示 |
| **商道融绿** | 在14个核心议题中包含"负面事件"监测；ESG风险雷达系统(ESG Risk Radar System)实时扫描 |
| **万得(Wind)** | 争议事件得分占总分30%（3/10分），基于新闻舆情/监管处罚/法律诉讼评估，每日更新，AI驱动 |
| **中证** | 一票否决制：重大环境污染/危害公共安全/重大财务造假直接否定评级；月度更新外有临时调整机制 |
| **妙盈科技** | NLP知识图谱实时监控；传统披露+另类数据+社交媒体多源交叉验证 |
| **MSCI（参考）** | 争议事件扣减关键事项得分；根据影响性质和范围评估恶劣程度，分为4个等级 |

#### B.2.3 量化影响：关键学术发现

| 研究 | 核心发现 |
|------|----------|
| **Capelle-Blancard & Petit (2019)** | 负面ESG新闻导致公司市值平均下降0.1%；投资者对媒体报道的反应强于公司自身信息披露；正面ESG新闻未产生显著正向收益 |
| **Ruige (2021)** | ESG争议事件在5天窗口期内对股票收益率产生-1.1%至-1.7%的显著负面影响 |
| **Clarity AI (2023)** | 分析10,000+事件/1,500+企业：争议事件6个月内导致-2%至-5%市值损失；高严重度事件平均-5%；产品与服务管理失当类最严重(-11.8%)；环境类次之 |
| **UCL研究 (2023)** | 基于1.14亿条推文：社交媒体ESG风险事件导致-0.29%的异常收益，主要由社会和治理类别驱动 |
| **MDPI中国研究 (2025)** | ESG争议与中国企业ESG异常表现显著负相关；客户关系稳定性可缓解负面影响；强盈利能力和高管绿色认知有调节作用 |
| **Krüger (2015)** | 投资者对ESG负面事件的反应显著强于正面事件（"负面偏差"效应） |
| **Serafeim & Yoon (2022)** | ESG评级分歧较大的公司，其ESG新闻对股价的影响更为显著 |

### B.3 影响衰减曲线

#### B.3.1 概念

ESG舆情事件对评级和股价的影响并非永久持续，而是随时间推移逐渐衰减。衰减速度取决于：
- 事件的严重程度
- 公司的应对措施（整改/赔偿/道歉）
- 媒体的持续关注度
- 行业特征

#### B.3.2 衰减曲线模型

| 模型参数 | 低严重度事件 | 中等严重度事件 | 高严重度事件 |
|----------|-------------|---------------|-------------|
| **初始影响（日异常收益）** | -0.1% ~ -0.3% | -0.3% ~ -1.0% | -1.0% ~ -3.0% |
| **半衰期（影响减半时间）** | 1-3个交易日 | 5-15个交易日 | 20-60个交易日 |
| **6个月累计影响** | -1% ~ -2% | -2% ~ -3% | -3% ~ -5% |
| **12个月累计影响** | 基本消退 | -1% ~ -2% 残留 | -2% ~ -5% 残留 |
| **评级恢复周期** | 1-2个评级周期 | 2-4个评级周期 | 4-8个评级周期 |

#### B.3.3 学术支持

Moody's (2022) 研究发现，ESG风险管理文化具有持续性：曾经发生过ESG争议的公司，未来发生新争议的概率显著更高（争议"惯性"效应）。改善ESG管理文化后，争议事件发生率随之下降。

Deloitte研究表明，ESG评分的短期冲击半衰期不超过2天（短期衰减约70%），但长期冲击的半衰期因ESG表现而异——ESG表现较好的公司长期衰减更快。

#### B.3.4 衰减函数的数学描述

常见建模方法：

**方法一：指数衰减模型**
```
影响(t) = 初始影响 × e^(-λt)
其中 λ = ln(2) / 半衰期
```

**方法二：分段衰减模型**
```
阶段1 (事件窗口，t为0-5日): 冲击阶段，影响最大
阶段2 (衰减期，t为5日-3月): 快速衰减
阶段3 (残余期，t为3月-12月): 缓慢衰减趋于0
```

**方法三：基于NLP的持续时间分类**
- ML-ESG-3任务：将ESG影响持续时间分为短期/中期/长期
- DynamicESG数据集：从新闻文章中动态推断ESG评级变化及其持续时间

### B.4 舆情影响的量化方法

#### B.4.1 事件研究法 (Event Study)

**原理**: 在有效市场假设下，通过比较事件窗口期的实际收益与预期收益（基于市场模型估算），计算异常收益(AR)和累计异常收益(CAR)。

**标准步骤**:
1. 确定事件日（事件首次报道日期）
2. 设定估计窗口（通常120-250个交易日）
3. 设定事件窗口（如[-1,+1]、[-5,+5]、[-10,+10]）
4. 估算市场模型参数
5. 计算异常收益 ARᵢₜ = Rᵢₜ - (α̂ᵢ + β̂ᵢRₘₜ)
6. 计算累计异常收益 CARᵢ(τ₁,τ₂) = ΣARᵢₜ
7. 统计检验（H₀: CAR = 0）

#### B.4.2 双重差分法 (Difference-in-Differences)

Clarity AI采用Synthetic Difference in Difference模型：
- 构造合成对照组（加权平均可比公司）
- 最大化事件前期权表现相似度
- 事件后差异归因为争议事件的影响
- 在5%水平上检验统计显著性

#### B.4.3 争议评分模型

**Refinitiv/Thomson Reuters方法**：
- 23个ESG争议话题
- 百分比排名分数
- 放大重大争议事件对综合评分的影响
- 争议评分 = ESG评分 + 争议调整 → ESGC综合评分

**Wind ESG方法**：
- 管理实践得分（7分，反映长期基本面）
- 争议事件得分（3分，反映短期冲击）
- 综合得分 = 管理实践 + 争议事件
- 每日更新，阈值触发评级调整（1.5分变动）

#### B.4.4 NLP驱动的实时监控

- **新闻舆情分析**：NLP分类争议事件类型、严重程度
- **社交媒体情绪**：Twitter/微博/股吧文本情绪分析
- **监管公告解析**：自动提取处罚类型、金额、整改要求
- **知识图谱关联**：识别关联方、供应链传导路径
- **影响持续时间推断**：ML-ESG任务，预测事件影响的短期/中期/长期属性

### B.6 关键结论与平台设计启示

1. **多源舆情聚合**：整合新闻、社交媒体、监管公告、法律诉讼等多渠道数据
2. **严重度分级**：建立三级（高/中/低）或四级（非常严重至轻微）严重度体系
3. **衰减建模**：基于指数衰减或分段衰减函数建模，支持半衰期参数化配置
4. **实时监控**：利用NLP技术实现日频舆情监控和自动化争议事件标注
5. **评级联动分析**：追踪争议事件→评级调整的时间序列因果关系
6. **行业差异化**：不同行业对同类争议事件的敏感度不同（如环境事件对矿业影响大于金融业）
7. **跨机构对比**：同一事件在不同评级机构的反映速度和幅度差异分析
